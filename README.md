# Task Manager API (Asynchronous Backend)

RESTful API сервис для управления задачами, спроектированный с учетом высокой производительности и асинхронности.

## 🛠 Стек технологий
* **Язык:** Python 3.11+
* **Фреймворк:** FastAPI (Asynchronous)
* **База данных:** PostgreSQL + asyncpg (драйвер)
* **ORM:** SQLAlchemy v2 (Асинхронный паттерн)
* **Миграции:** Alembic
* **Валидация данных:** Pydantic v2
* **Тестирование:** Pytest + HTTPX (ASGITransport)
* **Контейнеризация:** Docker / Docker Compose

## 🚀 Ключевой функционал
* Полностью асинхронная архитектура от обработки запроса до работы с базой данных.
* Архитектура спроектирована с использованием паттерна Dependency Injection (FastAPI Depends).
* Автоматическая генерация и применение миграций базы данных.
* Покрытие интеграционными тестами с изоляцией окружения через `dependency_overrides`.
* Быстрое развертывание всего окружения (API + База данных) одной командой.

## 📦 Как запустить проект локально

1. Клонируйте репозиторий:
```bash
git clone https://github.com
cd Task-Manager
```

2. Запустите проект через Docker Compose:
```bash
docker-compose up --build
```
После этого API будет доступно по адресу `http://localhost:8000`, а интерактивная документация — `http://localhost:8000/docs`
